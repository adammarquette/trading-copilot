# CLAUDE.md

Agent instructions for this repository are maintained in **`AGENTS.md`** (the cross-tool standard), so the same
rules apply whether you're driven by Claude Code, Copilot, or another agent. Follow the root `AGENTS.md`
(imported below), **plus the nearest `AGENTS.md`** in whatever subtree you're editing.

**Role contracts are not auto-loaded.** If you are reviewing a change, or touching CI/CD, the container image,
compose, or deploy, open the matching contract from the role index at the top of `AGENTS.md` **before you start**
— it will not arrive on its own.
